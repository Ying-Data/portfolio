# Portfolio, Ying Zhao

Personal portfolio site for **Ying Zhao**, a data analyst in Antwerp, Belgium.

**Live site: [ying-data.github.io/portfolio](https://ying-data.github.io/portfolio/)**

A single, hand-built HTML/CSS page (no framework, no build step) covering who I am, how I work, and three end-to-end analytics projects. Built to load fast and render cleanly on mobile and Safari.

## Featured projects

- **[Olist Customer Retention](https://github.com/Ying-Data/olist-retention-analysis)**: why 97% of an e-commerce platform's buyers never return, and a R$498K-a-year retention opportunity. Python, Random Forest, Power BI.
- **[Belgium Property Valuation](https://github.com/Ying-Data/belgium-real-estate)**: a fair-value model over 15,254 listings that flags mispriced homes. Python, Random Forest, Power BI.
- **[TeleCalifornia Churn Intelligence](https://github.com/Ying-Data/telecalifornia-churn-analysis)**: predicting which telecom customers churn (AUC 0.93) and the $3.68M behind them. Python, Random Forest, Power BI.
